**MDOptimizer** — это мощный, полностью прозрачный и автономный Batch-скрипт для ультимативной «post-install» настройки Windows 10 и 11. Одно нажатие — и ваша система очищена от телеметрии, оптимизирована для игр, а все нужные программы, драйверы и обход блокировок установлены.

> 🛡️ **Прозрачность и Безопасность:** Скрипт работает в формате **Standalone (Всё в одном `.bat` файле)**. Откройте его через Блокнот и убедитесь сами — код полностью открыт, загрузки идут только с официальных серверов (Winget, GitHub, Microsoft). Никаких скрытых троянов или майнеров.

---

## 🚀 Что нового в версии 1.2?

Обновление v1.2 превращает скрипт из простого установщика в профессиональный комбайн для настройки ОС.

* 🎬 **Анимированный Roll-up интерфейс:** Забудьте про скачущие строки. Новый UI плавно сворачивает огромные меню после выбора, оставляя консоль чистой и эстетичной. При запуске добавлена красивая анимация инициализации.
* 💽 **Умный файл подкачки (Своп):** Забудьте о микрофризах в играх (Rust, Tarkov). Скрипт предлагает задать жесткий размер подкачки (16 ГБ, 12 ГБ или 8 ГБ) в зависимости от вашего объема ОЗУ.
* 🛡️ **Продвинутый Zapret:** Теперь ваши кастомные списки доменов не перезаписывают оригиналы, а аккуратно **сливаются (merge)** со свежими базами автора утилиты.
* 🧹 **Тотальный Debloat:** Добавлено отдельное меню для ювелирного удаления 16+ видов системного мусора (включая полное уничтожение следов OneDrive, Copilot, BitLocker и телеметрии).
* 🎮 **DirectX & Deep Clean:** Добавлена установка End-User Runtimes для старых игр и модуль глубокой очистки кэша системы по завершении работы.

## ✨ Основной функционал

<details>
<summary><b>📦 Программы и Библиотеки</b> <i>(Нажмите, чтобы развернуть)</i></summary>

Установка происходит в тихом режиме через официальный менеджер **Winget**:
* **Гейминг и база:** Steam, Discord, DirectX, Visual C++ Redistributable (AIO сборка x86/x64), Java (8, 17, 21), .NET 8.
* **Утилиты:** 7-Zip, WinRAR, qBittorrent, WizTree.
* **Браузеры на выбор:** Google Chrome, Yandex Browser, Opera GX, Brave (с умной цветной индикацией в консоли).
* **Медиа:** Снос неповоротливых плееров Windows 11 (ZuneVideo/Music) и установка легкого VLC.
</details>

<details>
<summary><b>⚙️ Оптимизация системы</b> <i>(Нажмите, чтобы развернуть)</i></summary>

* Активация Windows (надежная HWID привязка через Microsoft Activation Scripts).
* Отключение UAC (Контроль учетных записей).
* Отключение фоновой работы UWP-приложений (экономия ОЗУ).
* Схема питания «Максимальная производительность».
* Отключение акселерации мыши (мастхэв для шутеров).
* Уменьшение задержки всплывающих меню с 400мс до 20мс.
* Снятие сжатия обоев рабочего стола (100% качество).
* Отключение "Оптимизации доставки" и гибернации (освобождает место на диске).
</details>

<details>
<summary><b>🌐 Обход блокировок (Zapret)</b> <i>(Нажмите, чтобы развернуть)</i></summary>

Скрипт автоматически скачивает свежий релиз [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) от **Flowseal**.
* Создает папку `C:\Zapret_Bypass` и вносит её в исключения Защитника Windows.
* Предлагает слияние ваших кастомных списков доменов с базами разработчика (через облако).
* Вшивает обновленный файл `hosts` для починки Telegram Web.
</details>

## 🛠️ Как использовать

Вам не нужны архивы или сложные инструкции. Установка происходит в 3 клика:

1. Перейдите в раздел **[Releases](../../releases)** (справа).
2. Скачайте файл **`MDOptimizer.bat`**.
3. Запустите его настраиваемом ПК *(скрипт сам запросит права Администратора)*.

> **💡 Система Шаблонов:** Надоело каждый раз отвечать на вопросы консоли? В ручном режиме скрипт предложит сохранить ваш выбор в отдельный `.bat` шаблон. В следующий раз просто запустите его и введите `Подтверждаю` — MDOptimizer сделает всё сам в фоновом режиме!
