**MDOptimizer** — это мощный и удобный Batch-скрипт для быстрой «post-install» настройки свежеустановленной Windows 10 или 11. Он экономит часы рутинной работы, автоматически скачивая нужное ПО, оптимизируя систему и настраивая обход блокировок.

> 🌐 **ВАЖНО:** Твикер работает в формате **Standalone (Всё в одном файле)**. Для скачивания программ, активатора и пользовательских списков требуется активное подключение к интернету!

## ✨ Что умеет скрипт?

* 🔑 **Активация Windows:** Безопасная HWID активация (Microsoft Activation Scripts) запускается напрямую из облака.
* 💾 **Система Шаблонов:** Создавайте собственные сборки! Скрипт позволяет сохранить ваш выбор программ и твиков в отдельный файл-шаблон. Запустите его на любом ПК, нажмите «Подтверждаю», и он всё установит автоматически.
* 📦 **Тихая установка программ (через Winget):** Steam, Discord, qBittorrent, 7-Zip, WizTree.
* 🌐 **Браузеры на выбор:** Умная установка Google Chrome, Yandex Browser, Opera GX и Brave (можно выбрать сразу несколько).
* 📚 **Обновление библиотек:** Visual C++ Redistributable (AIO сборка x86/x64), Java (8, 17, 21), .NET 8 Desktop Runtime, DirectX.
* 🎬 **Медиаплееры:** Удаление стандартных громоздких плееров Windows 11 (ZuneVideo/Music) и замена их на легкий VLC.
* 🛡️ **Обход блокировок (Zapret):**
  * Автоматически качает свежий релиз Zapret.
  * Умная интеграция: списки `lists.zip/rar` скачиваются напрямую с GitHub, а архиватор 7-Zip устанавливается автоматически для их распаковки.
  * Вшивает обновленный файл `hosts` для починки Telegram Web.
* ⚡ **Оптимизация и Debloat:**
  * Включение темной темы Windows.
  * **Отключение UAC (Контроль учетных записей):** Убирает бесящие экраны подтверждения прав. *Внимание: ради безопасности системы в «Стандартном» шаблоне эта опция по умолчанию отключена, но вы можете включить её в ручном режиме!*
  * Включение схемы питания «Максимальная производительность».
  * Удаление мусорных UWP приложений (OneDrive, Карты, Виджеты).

## 🛠️ Как использовать

Никаких архивов и папок! Установка стала максимально простой:
1. Перейдите в раздел **Releases** (справа на странице GitHub).
2. Скачайте всего один файл — **`MDOptimizer.bat`**.
3. Запустите его двойным кликом на вашем ПК. 
   > *Скрипт автоматически запросит права Администратора, необходимые для внесения изменений.*

### ⚙️ Управление в скрипте
* **Ручной режим (Нажмите Enter при запуске):** Скрипт проведет вас по 15 шагам. Отвечайте `Y` (Да) или `N` (Нет). Поддерживается русская раскладка (`Н` / `Т`).
* **Автоматический режим (Введите "Подтверждаю"):** Скрипт выполнит всю работу полностью в фоне по выбранному шаблону.
* **Просмотр состава:** В главном меню нажмите `2`, чтобы заранее увидеть, какие именно пункты будут установлены автоматически.
* **Совет:** Если консоль внезапно "замерла" (вы случайно кликнули мышкой) — просто нажмите клавишу `ESC`.
