# 🚀 MDOptimizer

**MDOptimizer** — это мощный и удобный Batch-скрипт для быстрой «post-install» настройки свежеустановленной Windows 10 или 11. Он экономит часы рутинной работы, автоматически скачивая нужное ПО, оптимизируя систему и настраивая обход блокировок.

> 🌐 **ВАЖНО:** Для корректной работы программы требуется активное подключение к интернету!

## ✨ Что умеет скрипт?

* 🔑 **Активация Windows:** Интегрированная поддержка безопасной HWID активации (через Microsoft Activation Scripts).

* 💾 **Система Шаблонов (Новое в v1.1!):** Создавайте собственные сборки! Скрипт позволяет сохранить ваш выбор программ и твиков в отдельный файл-шаблон. Запустите этот шаблон на любом ПК, нажмите «Подтверждаю», и он всё установит автоматически.

* 📦 **Тихая установка программ (через Winget):** Steam, Discord, qBittorrent, 7-Zip, WizTree.

* 🌐 **Браузеры на выбор:** Умная установка Google Chrome, Yandex Browser, Opera GX и Brave (можно выбрать сразу несколько).

* 📚 **Обновление библиотек:** Visual C++ Redistributable (AIO сборка x86/x64), Java (8, 17, 21), .NET 8 Desktop Runtime, DirectX.

* 🎬 **Медиаплееры:** Возможность удалить стандартные громоздкие плееры Windows 11 (ZuneVideo/Music) и заменить их на легкий VLC.

* 🛡️ **Обход блокировок (Zapret):**

  * Автоматически скачивает свежий релиз Zapret с GitHub.

  * *Умная зависимость:* если вы соглашаетесь на Zapret, скрипт сам предварительно установит 7-Zip для корректной распаковки ваших кастомных `lists.zip` / `lists.rar`.

  * Предоставляет подробную пошаговую инструкцию по настройке и вшивает обновленный файл `hosts`.

* ⚡ **Оптимизация и Debloat:**

  * Включение темной темы Windows и приложений.

  * Отключение UAC (назойливых уведомлений администратора).

  * Включение схемы питания «Максимальная производительность».

  * Удаление мусорных UWP приложений (OneDrive, Карты, Виджеты, Представление задач, Контроль памяти).

* 🧹 **Очистка мусора:** Автоматическая очистка кэша обновлений Windows и папки Temp после завершения всех установок.

## ⚙️ Управление в скрипте

Скрипт поддерживает несколько режимов работы и имеет защиту от случайных нажатий:

* **Ручной режим (нажмите Enter при запуске):** Скрипт будет спрашивать ваше разрешение перед установкой каждого компонента. Отвечайте `Y` (Да) или `N` (Нет). Можно использовать русскую раскладку (`Н` / `Т`). Нажатие `Enter` означает «Да».

* **Автоматический режим:** Введите слово `Подтверждаю` на стартовом экране, и скрипт сделает всю работу полностью в фоне по текущему шаблону (по умолчанию — Стандартному).

* **Просмотр состава шаблона:** Введите цифру `2` в главном меню, чтобы заранее увидеть весь список того, что будет установлено в автоматическом режиме.

* **Совет:** Если консоль внезапно "замерла" (вы случайно кликнули мышкой и включился режим выделения текста) — просто нажмите клавишу `ESC`.
